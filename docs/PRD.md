# PRD: FinSight

## 목표
카드사·은행에서 받은 CSV 명세서를 올리면, 지출이 어디로 새는지를 5분 안에 알려준다.

## 사용자
가계부 앱에 매번 손으로 입력하다 포기한 개인. 카드 명세서는 매달 나오지만 열어보지 않는다.
한국 거주, 원화(KRW) 거래, 국내 은행·카드사 CSV를 사용한다. 계정당 1인 사용.

## 핵심 기능
1. **CSV 업로드 & 자동 파싱** — 카드/계좌 별칭을 선택하고 파일을 업로드한다. 인코딩(EUC-KR/UTF-8)을 감지하고 첫 20행에서 원본 값을 제거한 컬럼 의미·형식 정보로 매핑을 추론한다. 사용자가 매핑·거래 유형·청구월을 확인한 뒤 저장한다. 불확실한 중복은 추가/중복 여부를 확인한다. 원본은 Supabase Storage에 보관하며 파일당 4MB·10,000행까지 지원한다.
2. **카테고리 자동 분류** — 고정 12개 카테고리 안에서 Claude가 거래를 분류. 사용자가 개별 거래를 고치면 "이 가맹점 → 이 카테고리" 규칙으로 저장돼 다음부터 자동 적용.
3. **기간별 지출 추이** — 월별·카테고리별 지출 변화. (Pro)
4. **구독 누수 & 이상거래 탐지** — 정기결제로 판정된 항목 목록과 월 합계, 금액 인상 감지. 카테고리 중앙값 대비 이상치 거래. **탐지는 전부 코드로 계산한다.** (Pro)
5. **AI 요약 & 절약 인사이트** — 이미 계산된 숫자를 근거로 Claude가 요약 문장과 절약 제안을 작성. 모든 문장은 근거 거래로 링크된다. (Pro)

## 요금제

| | Free | Pro |
|---|---|---|
| 업로드 · 원본 보관 | ✓ | ✓ |
| 카테고리 자동 분류 | ✓ | ✓ |
| 해당 월 카테고리별 지출 요약 | ✓ | ✓ |
| 거래별 카테고리 수정 | ✓ | ✓ |
| 기간별 추이 | — | ✓ |
| 구독 누수 탐지 | — | ✓ |
| 이상거래 탐지 | — | ✓ |
| AI 요약 & 절약 인사이트 | — | ✓ |
| 리포트 내보내기(CSV) | — | ✓ |

경계 원칙: **여러 달치 데이터가 쌓여야 의미가 생기는 기능은 전부 Pro.** Free 사용자도 계속 업로드하며 데이터를 쌓게 되고, 쌓일수록 Pro의 가치가 커진다.

업로드와 자동 분류는 두 플랜 모두 제공하되 운영 한도가 있다. 모델 호출은 사용자당 UTC 하루 300회·분당 20회(재시도 포함)이며 한도 도달 시 재시도 가능 시각을 안내한다. 기존 데이터 열람·수동 수정은 계속 가능하다. 같은 출처의 동일 파일은 기존 업로드·매핑을 재사용한다.

**지출의 의미:** 저장 금액은 절댓값이며 거래별로 지출·수입·환불·이체를 구분한다. 총지출과 카테고리 합계는 지출-환불이다. 급여, 본인 계좌 이체, 카드대금 납부는 총지출에 포함하지 않는다. 분류가 애매한 행은 사용자가 확인하며 저장 후에도 거래 유형을 수정할 수 있다.

## MVP 제외 사항
- 팀 / 다중 사용자 / 공유
- 은행 오픈뱅킹 API 자동 연동 (CSV 업로드만)
- 예산 설정, 목표, 푸시 알림
- 모바일 네이티브 앱
- 다국어 / 다통화 (KRW 고정)
- 데이터 자동 만료 정책 (사용자가 지울 때까지 보관)
- 사용자가 카테고리 자체를 추가/삭제하는 기능 (거래별 수정만 허용)

## 디자인
- 라이트/다크 토글. 시스템 설정을 초기값으로 쓰고 사용자 선택을 `localStorage`에 저장.
- 무채색 기반 + 데이터 색상(지출 증가/감소)만 유채색. 브랜드 포인트 색은 링크·포커스 링에만.
- 도구처럼 보여야 한다. 랜딩과 대시보드가 같은 톤을 쓴다.
- 상세 규칙은 `docs/UI_GUIDE.md`.
