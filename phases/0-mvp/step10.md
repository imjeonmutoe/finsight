# Step 10: landing

## 읽어야 할 파일

먼저 아래 파일들을 읽고 프로젝트의 아키텍처와 설계 의도를 파악하라:

- `/docs/PRD.md` — 목표, 사용자, 핵심 기능, **요금제 표**
- `/docs/UI_GUIDE.md` — **전체.** 특히 안티패턴 표와 다크모드 구현 규칙
- `/docs/ARCHITECTURE.md` — `## 화면 인벤토리`의 S1·S1b, `## 보안`
- 이전 step 산출물: step 8의 컴포넌트들(카드·버튼을 재사용한다), `src/app/layout.tsx`

## 작업

담당 화면: **S1**(익명) · **S1b**(로그인됨).

### `/` 랜딩 — 정적 1페이지

섹션 구성:
1. **히어로** — "카드 명세서 CSV를 올리면 지출이 어디로 새는지 보여드립니다" 수준의 한 줄. 랜딩 히어로만 중앙 정렬 허용
2. **기능 3개** — 자동 분류 / 지출 추이 / 구독 누수 탐지. 각 항목에 실제 화면 스크린샷 대신 **간결한 설명 + 예시 수치**를 쓴다(스크린샷 자산이 없다)
3. **가격표** — PRD의 Free/Pro 표를 그대로. **가격은 원화 표기**
4. **CTA** — Google 로그인으로

로그인 상태(S1b)면 CTA를 "대시보드로"로 바꾼다.

**step 8에서 만든 카드·버튼 컴포넌트를 재사용한다.** 랜딩과 대시보드가 같은 톤이어야 한다는 게 UI_GUIDE 원칙 1이다.

### 테마 토글

`localStorage` + `<html data-theme>`. FOUC 방지 인라인 스크립트는 step 0에서 `layout.tsx`에 넣었으니 토글 컴포넌트만 추가한다.
`prefers-color-scheme`은 최초 방문 기본값으로만 쓰고, 사용자가 토글하면 `localStorage`가 우선한다.

### `/privacy` — 개인정보처리방침

**법적 필수다. 협상 대상이 아니다.** 거래 내역이 Anthropic(미국)으로 전송되는데, 한국 개인정보보호법상 국외 이전은 고지 대상이고 대상이 금융 거래 내역이다.

정적 텍스트 한 페이지. 최소 내용:
- **수집 항목** — Google 계정 이메일, 업로드한 CSV 원본, 파싱된 거래 내역(날짜·가맹점명·금액·카테고리)
- **처리 목적** — 지출 분석 및 시각화
- **보유 기간** — 사용자가 삭제할 때까지. 계정 삭제 시 전부 삭제
- **국외 이전** — 대상과 항목을 명시:
  | 수탁자 | 국가 | 이전 항목 | 목적 |
  |---|---|---|---|
  | Anthropic | 미국 | 가맹점명·금액·날짜 | 카테고리 분류, 요약 문장 생성 |
  | Supabase | 미국 | 계정 정보, 원본 CSV, 거래 내역 | 인증·데이터 저장 |
  | Vercel | 미국 | 접속 로그 | 호스팅 |
  | Polar | 미국 | 결제 정보 | 구독 결제 |
- **삭제 요청 방법** — 설정 화면의 전체 데이터 삭제, 그리고 문의 경로
- **회수 불가 고지** — "Anthropic에 이미 전송된 데이터는 회수할 수 없습니다"

`/login` 화면(step 3)에 이 페이지 링크가 이미 있다.

### Vercel Analytics

`@vercel/analytics` 패키지 설치 후 `layout.tsx`에 컴포넌트 추가. 이게 계측의 전부다 — 이벤트 테이블은 MVP에 없다.

## Acceptance Criteria

```bash
npm run lint
npm run build
npm test
```

**TDD 가드: `src/components/*.tsx`는 테스트 파일이 먼저 있어야 한다.** (`page.tsx`는 면제)

테스트에 반드시 포함할 것:
- 테마 토글이 `data-theme`을 바꾸고 `localStorage`에 저장하는가
- `localStorage`에 값이 없을 때 `prefers-color-scheme`을 따르는가
- 로그인 상태에 따라 CTA 문구가 바뀌는가

수동 확인:
```bash
npm run dev
# 라이트/다크 토글 후 새로고침 → 선택이 유지되는가
# 새로고침 시 흰 화면이 번쩍이지 않는가 (FOUC)
# /privacy 접근 가능하고 국외 이전 표가 있는가
```

## 검증 절차

1. 위 AC 커맨드를 실행한다.
2. 아키텍처 체크리스트:
   - UI_GUIDE 안티패턴을 하나도 쓰지 않았는가? (gradient text, glass morphism, 보라색, blur orb, 네온 글로우)
   - 색을 하드코딩하지 않고 토큰만 썼는가?
   - step 8의 컴포넌트를 재사용했는가? 랜딩용으로 카드/버튼을 새로 만들지 않았는가?
   - 가격이 원화 표기인가?
   - `/privacy`에 국외 이전 대상 4곳이 전부 있는가?
3. `phases/0-mvp/index.json`의 step 10을 업데이트한다.

## 금지사항

- UI_GUIDE 안티패턴 표의 항목을 쓰지 마라. 이유: 표에 이유가 적혀 있다. 특히 랜딩은 gradient hero의 유혹이 큰 곳이다.
- 랜딩 전용 카드·버튼 컴포넌트를 새로 만들지 마라. 이유: UI_GUIDE 원칙 1 — 랜딩과 대시보드가 같은 톤이어야 한다.
- `/privacy`를 생략하거나 나중으로 미루지 마라. 이유: 금융 거래 내역의 국외 이전 고지는 법적 의무다.
- 스크롤 리빌 애니메이션을 넣지 마라. 이유: UI_GUIDE 애니메이션 규칙에서 금지했다.
- 대기자 이메일 수집 폼을 만들지 마라. 이유: 요청받지 않았다. CTA는 Google 로그인이다.
- 이벤트 추적 코드를 직접 작성하지 마라. 이유: 계측은 Vercel Analytics만으로 정했다.
